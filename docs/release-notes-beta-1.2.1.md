# Beta 1.2.1

- Node mode now fits and centers the mapping on launch. A new Fit to View button (or the `F` / `Home` keys) refits it at any time.
- Layer labels no longer pile up when zoomed out; they clip to their node and hide once too small to read, and the canvas can zoom out much further.
- The Target Filter panel now resizes by height only, with a grip that no longer covers the panel's rounded corner.
