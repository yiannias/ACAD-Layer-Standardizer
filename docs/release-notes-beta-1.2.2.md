# Beta 1.2.2

- Column mode connections now curve with the same smooth S-curves as Node mode, including the line you drag while pairing.
- Column mode has a wider gap between the Source and Target lists so the curves read clearly.
- The mapping editor is built with size-optimized release settings, making the installer smaller.
- Node mode shows Source and Target search fields in the group headers.
- Layer labels stay visible at any zoom level, however small, clipped to their node.
