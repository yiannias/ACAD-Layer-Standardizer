# Beta 1.2

This release makes the Rust mapping editor the standard `LSTDR` experience.

- Added Node and Column mapping modes with match-status colors and source-to-target pairing feedback.
- Added searchable layer lists, selectable targets that highlight their source layers, and visible pair counts or names.
- Added target-standard switching, category filters, Apply, Apply & Remember, and confirmed empty-layer purge through the AutoCAD bridge.
- Refined the floating status bar, resizable Target Filter panel, spacing, row outlines, and match colors.
- Preserved the route to choose a standard when the saved reference file is unavailable.

The installer includes the AutoCAD plug-in and Rust mapping editor for AutoCAD 2021–2027.
